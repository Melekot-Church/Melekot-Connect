### Melekot Connect

Clone of https://github.com/ChurchCRM/CRM/
### Description:

**Melekot Connect** is a comprehensive church member management system designed for Melekot Church. This innovative platform aims to streamline the management of church members, enhance communication, and foster a stronger sense of community within the church. 

Features

  1. Congregation Management
  Families
  Persons
  Self Registration
  Online Verification
  Notes
  Properties
  Finances
  Donations
  Envelope
  Deposits
  Events
  Groups
  Sunday School
  Calendar
  Fundraiser
  Reports and Queries
  Volunteers
  Data Import / Export
  Backup / Restore
  Localization
  User Management
  External Integ
